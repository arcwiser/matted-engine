# tools/assets — Asset Validator (TASK-B1)

Stdlib-only Python validator for the glTF/GLB/OBJ files consumed by the
TASK-2 asset pipeline (`engine/assets/`, AgentB). Nothing here touches
engine code.

| File | What it is |
|---|---|
| `validate_assets.py` | The validator (single file, `--manifest`, `--selftest`) |
| `make_fixtures.py` | Deterministically regenerates everything in `fixtures/` |
| `fixtures/` | 3 valid + 5 corrupt fixture files + `manifest.example.json` |

## Usage

```bat
:: validate one or more files
python tools\assets\validate_assets.py model.glb scene.gltf mesh.obj

:: validate a whole pack against expected counts (TASK-B2 gate)
python tools\assets\validate_assets.py --manifest assets\test\manifest.json

:: self-check: validates the shipped fixtures and expects their outcomes
python tools\assets\validate_assets.py --selftest
```

Exit codes: **0** valid (warnings allowed) · **1** invalid (any ERROR) ·
**2** usage error. Every problem prints one line:

```text
file:line-or-path: SEVERITY: message
tools\assets\fixtures\bad_index.obj:line 30: ERROR: vertex index 99 out of range (count 8)
```

## What is checked

**glTF (.gltf):** JSON parses; every attribute (`POSITION`, `NORMAL`,
`TEXCOORD_0` required) and `indices` reference points at an existing
accessor; decoded index values are `<` the POSITION vertex count; POSITION
accessors have `min`/`max` and contain no NaN; accessor reads stay inside
their bufferView/buffer. Buffers may be `data:` URIs (base64) or external
files (resolved relative to the .gltf). Non-TRIANGLES primitive modes are
warned, not counted.

**GLB (.glb):** magic `glTF`, version 2, header length == file size,
4-byte-aligned chunks, first chunk is JSON, chunk sizes sum exactly to the
file size, then all the glTF checks against the BIN chunk.

**OBJ:** every `f` line must be a triangle (error, with line number); all
`v/vt/vn` indices (1-based or negative-relative) must be in range; warns
when `vn`/`vt` are absent (flat shading / no UVs).

**Manifest mode:** `manifest.json` is a JSON array of
`{ "file", "expected_tris", "expected_verts", "source", "license" }`
(paths relative to the manifest). Each file is validated and its actual
triangle/vertex counts must match the manifest — see
`fixtures\manifest.example.json` for the schema TASK-B2 uses.

## Fixtures

Generated by `make_fixtures.py` (re-run it to regenerate; do not hand-edit):

| Fixture | Expected |
|---|---|
| `tri_cube.obj`, `red_cube.gltf`, `box.glb` | 0 errors, 12 tris, 8 verts |
| `bad_index.obj` | ERROR (vertex index 99 out of range) |
| `non_tri.obj` | ERROR (quad face) |
| `nan_pos.gltf` | ERROR (NaN in POSITION min/max) |
| `bad_accessor.gltf` | 2 ERRORs (attribute + indices point at accessor 99) |
| `truncated.glb` | ERRORs (header length != file size, chunk overruns) |

Note: repo `.gitignore` ignores `*.obj` (MSVC objects) — negated with
scoped `!` rules for the asset data dirs so mesh fixtures stay tracked.
